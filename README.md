# StockTrendTracker

Daily analysis of political and geopolitical news to find liquid stocks and ETFs likely to
outperform over the following days to weeks. It explains the reasoning behind every pick and
keeps an honest, automatically scored track record.

**Status:** planning. See [docs/PLAN.md](docs/PLAN.md) for the full plan, phases and open
questions.

> Research and decision-support tool for personal use. Not investment advice; it never
> places trades.
